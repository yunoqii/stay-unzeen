- **Демо Zcash на mainnet** (0.01–0.05 ZEC), testnet для CI (владелец). Причина: NU7 на testnet, нет готового ZODL и фаусета.
- **Пул Ironwood** вместо Orchard (владелец, по ресёрчу).
- **Формат memo `unz1`** вместо JSON (владелец). Причина: JSON с refund/nonce/exp не помещается в 512 байт.
- **Новый порядок урезания** (владелец): чат → статистика → кабинет создателя → умный вывод → Meteora → Jito с несколькими vault → автоматизация NEAR Intents → лимитки/TP/SL → полный fair-launch → Jupiter.
- **Новые функции** в `docs/FEATURES.md` (владелец): лимитки/TP/SL, умный вывод, кабинет создателя, чат, статистика, режим баланса.
- **Весь UI, README, видео и демо — на английском** (владелец).
- **Агенты не коммитят**, коммиты делает лид после проверки (лид, чтобы не было конфликтов при параллельной работе).
