# Unzeen — функции

Согласовано с владельцем проекта 12.10.2026.

## Ядро (без этого нет демо)
- Аккаунт на anon-ключе (12 слов), без email и кошельков
- Баланс ZEC: пополнил один раз → мгновенные действия с баланса. Режим «оплата за действие» вырезан (12.10, приватность)
- Покупка / продажа на pump.fun и Meteora DBC; любой токен Solana через Jupiter
- Лаунч токена, создатель анонимен
- Claim creator fees на баланс
- Вывод ZEC на любой shielded UA, токенов — на новый Solana-адрес; **всегда** с каплей SOL на газ, задержкой и округлением суммы; позиция по токену — на одном vault пула
- Живая лента «unzeen купил…», страница токена
- Fair-launch: закрытые заявки (tlock) → атомарный create+buy (Jito)
- Verify: публичная проверка честности пула — Merkle-sum дерево обязательств + публичные vault + резерв ZEC; viewing key не публикуется никогда

- Режим исполнения: переключатель Now (1–3 с, единый priority fee пула, без Jito; только buy/sell/create) / Delayed (пачки 30–60 с) / Max privacy (5–15 мин) у кнопки покупки/продажи; режим по умолчанию — в профиле (по умолчанию Delayed)

## Дополнительно (входит в хакатонную версию)
1. **Приватные лимитки / TP / SL.** Ордера хранятся только в реестре пула, не on-chain → на них нельзя охотиться. Релейер следит за ценой и исполняет с vault. Типы: limit buy, limit sell, take-profit, stop-loss. Отмена в любой момент.
2. **Умный вывод (опционально).** Переключатель при выводе токенов: разбить на N частей (2–5) на N новых адресов со случайной задержкой (до M минут) + капля SOL на газ на каждый адрес. Газ и задержка есть всегда (базовый вывод); умный вывод добавляет разбиение на N адресов. По умолчанию выключен.
3. **Анонимный кабинет создателя.** Для токенов, созданных anon-ключом: накопленные и выведенные комиссии, объём, число холдеров, кривая/выпуск, кнопка claim.
4. **Анонимный чат под токеном.** Сообщения подписаны anon-ключом; публичный ник = короткий хэш `H(anonPubkey ‖ mint)` → под разными токенами ники разные и не связываются. Бейдж «creator» — по желанию создателя. Модерация: лимит частоты, минимальный баланс ZEC для постинга (анти-спам).
5. **Статистика Unzeen.** Публичная страница: общий объём, сколько ZEC прошло через shielded-пул, число сделок / лаунчей, топ токенов, распределение по площадкам.

6. **Панель безопасности токена** (решение 12.10). Mint/freeze authority отозваны или нет; топ-10 холдеров % и доля дева (без bonding curve и vault'ов пула); история дева — сколько токенов запускал, сколько слил (Helius); снайперы и бандлы в первых блоках — число и доля; прогресс bonding curve, graduated, LP сожжена/залочена; соцсети из метаданных. Для запусков через Unzeen — бейдж “Unzeen launch: dev anonymous, rules enforced” + **opt-in** репутация анонимного создателя (число запусков / рагов) без раскрытия личности; analyst проверяет, что это не связывает запуски сверх согласия создателя.
7. **Быстрая торговля.** Пресеты покупки 0.1 / 0.5 / 1 ZEC (настраиваемые) и продажи 25 / 50 / 100%; настройки слиппеджа и приоритета; позиция: PnL, средняя цена входа, свои сделки маркерами на графике (**считается только в браузере**); лента сделок токена с фильтрами: киты / дев / unzeen.
8. **Поиск токена по адресу контракта (CA).**

Все данные для 6–8 — только через наш бек (Helius/RPC), фронт к сторонним API напрямую не ходит.
