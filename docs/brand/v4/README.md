# Unzeen brand v4: лента заметнее (исследование → финал)

- `compare.png` — как было (плоская лента v3/D2a) и как стало (финал v4). **Главный лист для владельца.**
- `tape-kit.png` — набор лент:
  - плоская, для сравнения;
  - сложенная, уровень **full**;
  - сложенная, уровень **simple**;
  - двухслойная, full и simple;
  - каждая в 200, 48, 32 и 16 px и в wordmark.
