# Motion v2: спека для frontend

designer, 13.10.2026. Основа: `docs/FRONTEND.md` (раздел «Интерактив»), ресёрч `docs/design/zcash-ecosystem.md`. Прототипы (vanilla WAAPI, открываются локально, без сети): `docs/design/prototypes/motion-v2.html`, там же переключатель reduced motion. Внедрение на Motion (`motion/react`), код в `web/` пишет frontend.

## Принципы (не меняются)
- Каждое движение показывает **смену состояния**: «видно → скрыто», «твоё → общее», «ждём → зачислено». Декоративного движения нет.
- Один жест на весь продукт: **лента штриховки (redaction tape)**. Она закрывает то, что стало приватным. Затмение — для героя и бренда, штриховка — для интерфейса. Щитов, замков и частиц нет.
- Цифры без overshoot: `bounce: 0`. Easing по умолчанию `--uz-ease-expo-out` = `[0.16, 1, 0.3, 1]`. Анимируем только `transform`, `opacity`, `filter` (blur ≤ 12 px) и `stroke-dashoffset`.
- `<MotionConfig reducedMotion="user">` уже в корне. Для каждого эффекта ниже есть fallback: без движения в пространстве, ≤ 150 мс opacity.
- Все строки UI на английском, приведены дословно.

## Общий примитив: `<RedactionTape>`
Нужен один компонент, его используют M1, M2, M6, M8.
- Разметка: `span` absolute поверх контента, `background: var(--uz-zec-deep, #1a1405) repeating-linear-gradient(-45deg, var(--uz-zec) 0 1.4px, transparent 1.4px 6px)`, `box-shadow: inset 0 0 0 1px rgb(244 183 40 / .7)`, `border-radius: 3px`. Новый токен в `globals.css`: `--uz-zec-deep: #1a1405` (уже есть как `--uz-zec-ink`, можно переиспользовать).
- API: `<RedactionTape state="covered" | "lifted" | "hidden" from="left" | "right" />`.
- Covered: `scaleX 0 → 1`, `transformOrigin` по `from`, 420 мс (M1) или 180 мс (M2), ease `[0.16, 1, 0.3, 1]`.
- Lifted: `scaleX 1 → 0` к противоположному краю, 220 мс, ease-in `[0.7, 0, 0.84, 0]` (уходит быстро, не тянет внимание).
- `aria-hidden`; смысл передаёт текст статуса рядом, а не лента.
- Reduced: opacity 0 → 1 за 150 мс, без scale.

### M1 · Shielding tape (Top up → Credited)  · P0
- **Смысл:** деньги перешли в shielded-пул и больше не связаны с отправителем. Сейчас «Credited» — только жёлтая вспышка; добавляем жест «закрыто».
- **Последовательность** (по событию `status === "credited"`):
  1. строка «Incoming» закрывается лентой слева направо: `scaleX 0→1`, 420 мс, `[0.16, 1, 0.3, 1]`;
  2. через 0 мс статус меняется на `Credited · shielded, unlinkable` (существующий `layoutId`-индикатор PaySteps двигается как сейчас);
  3. строка «Private balance» считает вверх (`CountUp`, 600 мс, ease-out quart, без overshoot), цифры 900 мс линейно гаснут из `--uz-zec` в `--uz-paper`.
- **Motion:** `animate(tape, { scaleX: [0, 1] }, { duration: 0.42, ease: [0.16, 1, 0.3, 1] })`, затем `CountUp`.
- **Reduced:** лента появляется opacity за 150 мс, баланс сразу с итоговым числом.
- **Копирайт:** `Credited · shielded, unlinkable`. Если это расходится с ux-states.md, решает frontend.
- Прототип: блок M1.

### M2 · Identity collapse (новая строка ленты)  · P0
- **Смысл:** «тут был реальный кошелёк, мы его заменили». Сейчас слово «unzeen» скрамблится из шума. Новая версия рассказывает историю: адрес vault → тень → «unzeen».
- **Последовательность** (только для `fresh`-строк, пришедших по сокету):
  1. строка проявляется как сейчас (blur 12 → 0, 500 мс, layout spring bounce 0);
  2. через 260 мс в слоте «кто» показывается **адрес vault** (тот, что реально в транзакции, усечённый `7xKXa9…Qm2`, Geist Mono), он за 220 мс слева направо превращается в `░▒▓`;
  3. лента закрывает слот за 180 мс, под ней текст меняется на `unzeen` (Geist, обычный кегль), лента уходит вправо за 220 мс (ease-in).
  - Итого ≈ 900 мс, одна строка за раз; если пришло много, остальные получают только шаг 1 (очередь не копим).
- **Важно для приватности:** показываем только адрес vault пула, который и так публичен в транзакции. Никогда не показывать что-либо, связанное с пользователем. Если адрес vault в событии не приходит, шаг 2 пропускается: сразу `▓▒░` из `SHADE`.
- **Reduced:** сразу `unzeen`, строка opacity 150 мс.
- Реализация: расширить `ScrambleText` параметром `from` (исходная строка) или новый `CollapseIdentity`, DOM пишет напрямую, как сейчас.
- Прототип: блок M2.

### M3 · Contact (герой, первая загрузка)  · P1 · вау-момент #1
- **Смысл:** «тебя сейчас не станет видно». Один раз за сессию (флаг в `sessionStorage`).
- **Последовательность:**
  1. диск затмения стартует со смещением `(-3%, +2%)` от финальной позиции и за 1400 мс въезжает в фазу, ease `[0.22, 1, 0.36, 1]`;
  2. на 1050 мс в точке последнего контакта (вверху справа, там, где обод тоньше всего) вспыхивает «бусина» света (Baily's bead): радиальный градиент `#fff6dc → --uz-zec → прозрачный`, opacity `0 → 1 → 0`, scale `0.6 → 1.15 → 1`, 700 мс;
  3. корона (мягкое свечение вокруг обода) проявляется opacity 0 → 1 за 900 мс;
  4. параллельно, со сдвигом +200 мс, лента запускает M2 для первых 3 строк по очереди (каскад 300 мс).
- **WebGL:** в `eclipse-gl.tsx` это один uniform `uContact` (0 → 1) для сдвига диска и `uBead` (0 → 1 → 0) для вспышки. В video/static режимах шаг 1 делаем CSS-transform контейнера, бусина — отдельный абсолютный `div`.
- **Reduced / Save-Data:** финальный кадр, без вспышки.
- **Для видео:** пишем с `?eclipse=gl`, курсор неподвижен 2 секунды.
- Прототип: блок M3.

### M4 · Split and scatter (вывод)  · P1 · вау-момент #2
- **Смысл:** вывод нельзя сопоставить с покупкой: сумма делится на части и уходит в разное время на свежий адрес. Сейчас вывод «растворяется», но не показывает, **как** мы защищаем.
- **Когда:** после подтверждения вывода с включённым `Smart withdraw` (Parts > 1). Без Smart withdraw — текущее растворение.
- **Последовательность:**
  1. чип суммы `2,400,000 $PEPE` слева, пунктирная дорожка, справа `fresh address · 9xQ…k2` (адрес с пунктирной рамкой, Geist Mono);
  2. сумма разделяется на N чипов (N = parts, реальные значения из ответа API), чипы расходятся по вертикали на ±30 px за 300 мс;
  3. каждый чип едет по дорожке к адресу в **своём** темпе: позиция отражает реальную запланированную задержку части относительно `max delay` (шкала под дорожкой: `now`, `+2 min`, ...). Последние 10% пути — blur 0 → 6 px и opacity → 0.
  4. В реальном времени части ждут минуты: показываем сжатую анимацию (3–4 с) один раз, затем чипы стоят на своих позициях с подписью `leaves in 4m 12s`, и прогресс обновляется раз в секунду linear-движением.
- **Motion:** `motion.span` с `animate={{ x }}` по keyframes, `times` из задержек, `ease: "linear"` (это время, а не жест).
- **Reduced:** чипы сразу на позициях, без пути; подписи времени остаются.
- **Честность:** числа частей и задержек только из ответа API. Если API отдаёт только количество частей без сумм, чипы без сумм (`part 1 of 3`).
- Прототип: блок M4.

### M5 · Your leaf, nobody else's (Verify)  · P0
- **Смысл:** главный аргумент доверия для судей. «Мы доказываем твой баланс, не показывая чужие.»
- **Изменения в `merkle-trace.tsx`:**
  1. соседние листья рисуются не хэшами и не точками, а **маленькими лентами** (52×14, штриховка 55% opacity): лист есть, чей — неизвестно;
  2. путь от твоего листа к корню рисуется hairline-линией `--uz-zec` 1.6 px: `pathLength 0 → 1`, 900 мс, ease `[0.65, 0, 0.35, 1]`;
  3. узлы на пути загораются по мере прохода линии (шаг 300 мс), каждый `scale 1.6 → 1` за 300 мс;
  4. последним загорается корень, рядом расшифровывается его хэш (`DecryptText`, 420 мс) и подпись `root #100`.
- **Reduced:** путь и узлы сразу в финальном состоянии.
- Прототип: блок M5.

### M6 · Peek tape (балансы)  · P2
- **Смысл:** то же «спрятано по умолчанию», но нашим жестом, а не blur. Blur остаётся fallback.
- По Peek лента уходит вправо (220 мс, ease-in), цифры расшифровываются `DecryptText` (как сейчас). Под суммой тонкая линия `--uz-zec-a2` убывает `scaleX 1 → 0` за 5 с (автоскрытие, если оно есть в коде); по окончании лента возвращается слева (420 мс).
- Под лентой не реальные цифры, а фиксированная заглушка: правило из `peek.tsx` про утечку длины суммы сохраняется.
- **Reduced:** без движения ленты, opacity.

### M7 · Someone was here (пустые состояния)  · P2
- Иллюстрация empty (ledger из трёх линий, средняя закрыта штриховкой, `web/public/illustrations/empty.webp`) получает одну живую деталь: штриховка средней строки медленно дрейфует, `background-position` за 14 с линейно, бесконечно. Это фон, а не событие, поэтому только CSS и только пока элемент виден.
- **Reduced:** статично.
- Прототип: блок M7.

### M8 · Creator slot (превью запуска)  · P1
- **Смысл:** создатель анонимен с первой секунды.
- На `/launch`, пока пользователь вводит name/ticker, справа живое превью строкой ленты: `unzeen launched $TICKER · pump.fun`. Слот «кто» закрыт лентой постоянно (не снимается), тикер печатается по мере ввода (без анимации на каждый символ, только `layout` у строки).
- По успешному запуску: превью-строка улетает вверх в позицию первой строки ленты (shared `layoutId="feed-row-new"`), если пользователь переходит на `/`. Если нет — короткий flash `--uz-zec-a1` фона строки 600 мс.
- **Reduced:** без перелёта.

### M9 · Thin proof (Verify, бары solvency)  · P2
- Сейчас жёлтые бары во всю ширину. По правилу «жёлтый — свет, а не заливка» (см. ресёрч): бар 2 px высотой, заливается `scaleX 0 → value` за 600 мс со stagger 60 мс по строкам при первом показе; бейдж `Proven` — точка 6 px + текст, без жёлтого круга-заливки.
- **Reduced:** сразу финальные значения.

### M10 · Block tick (пульс сети)  · P2
- Точка `Live` в ленте сейчас просто жёлтая. Пусть она мигает **по реальному событию**: новый блок Zcash в сканере или новый слот на Solana от бека (если такое событие есть в API, иначе не делаем). Одна вспышка: `scale 1 → 1.8`, `opacity 1 → 0` у кольца вокруг точки, 600 мс.
- Нет события — нет пульса. Никакого бесконечного «дыхания» ради вида.
- **Reduced:** без кольца.

## Вау-моменты для видео-демо
1. **«Totality» (0:00–0:05):** первая загрузка главной. Затмение входит в фазу (M3), вспыхивает бусина, и сразу три строки ленты по очереди превращают адреса vault в `unzeen` (M2). Кадр, который объясняет продукт без слов: сделки реальные, автора нет.
2. **«Shielded» (середина ролика):** Top up из ZODL, QR → `Seen` → `Credited`: строка закрывается лентой (M1), баланс считает вверх. Затем вывод с Smart withdraw: сумма делится на части и уходит на свежий адрес с разными задержками (M4). Вместе это вся история «вошёл анонимно, вышел без связи».

Резерв для финала ролика: Verify (M5). Путь от «your leaf» к корню загорается, соседи остаются закрытыми.

## Что не делаем
- Частицы, «matrix»-дождь, glitch на всём экране, параллакс ради параллакса, бесконечные пульсации.
- Анимацию знака Zcash (правила бренда, см. `zcash-ecosystem.md`).
- Overshoot на числах, `transition: all`, hover-scale карточек.
