# X/Twitter: как оформлены крипто-проекты (ресёрч к бренду v3)

Ресёрч 13.10.2026, designer. 18 аккаунтов (по уточнению владельца: 15–20, не больше). Данные профилей (био, URL аватара и баннера) взяты через публичный FxTwitter API, картинки скачаны с pbs.twimg.com в оригинальном размере (аватар 400×400, баннер 1500×500), каждый аватар просмотрен в 48 и 32 px. Сайты ZecHub и zkproof.org разобраны по методу `hallmark study` (URL + скриншот, извлекались только визуальные факты).

Исходники и скриншоты лежат локально в `docs/design/x-research/`, список ссылок в `docs/design/x-research/sources.md`. **Это материалы третьих лиц: в git не коммитить** (лиду: добавить папку в `.gitignore` или не стейджить).

Ограничения: закрепы без логина в X не видны, поэтому их нет. Цвета, кроме ZecHub, оценены на глаз.

## Выводы

### Что делает аватар узнаваемым в 32–48 px
1. **Одна толстая форма, высокий контраст, максимум два цвета.** Выигрывают pump.fun, Zcash, Phantom, Monad, Aztec, Arcium. Проигрывают тонкие линии, градиентные полосы, хром и надписи: Penumbra, Railgun, ZecHub, Zashi.
2. **Фирменная заливка-фон** делает половину работы: фиолетовый Monad и Arcium, лаванда Phantom, жёлтый Zcash. У нас фирменный цвет — жёлтый на почти чёрном. Знак должен быть **сплошным жёлтым пятном**, а не тонким светом. Это главный урок против v2, где был тонкий ободок.
3. **Силуэт важнее детали.** Проверка: аватар в 24 px с прищуром. Если форма не угадывается, деталь лишняя.

### Какие баннеры работают
- **Типографика + один мотив** (Zcash «n●rmal», Penumbra, ZecHub). Лучший тип для нового аккаунта.
- **Паттерн / генеративка без текста** (Hyperliquid, Monad). Красиво, но ничего не объясняет, а нам надо объяснить продукт.
- **Продукт** (pump.fun: сторы и монеты). Работает, если сам продукт — картинка. Наша лента «unzeen bought …» и есть картинка.
- **Мем / арт** (Aztec, Zodl). Запоминается, но легко скатывается в AI-иллюстрацию.
- **Фото толпы** (Jupiter, Meteora). Только когда есть комьюнити.

### Клише в крипте (не делаем)
Фиолетовые градиенты со свечением, планеты и орбиты, хромированные 3D-объекты, щит и замок с эмодзи 🛡️, точечный «шифр-шум», летящие монеты, AI-иллюстрации-маскоты, тонкое кольцо-затмение (занято Penumbra), жёлтая монета (занята Zcash).

### Свободная ниша
Чёрный + жёлтый в приватности использует только сам Zcash, и только как монету. Цензурную плашку, коммитмент-скобки, Merkle-фигуру и «ленту без имён» не использует никто. Отсюда направления v3: `docs/brand/v3/overview.png`.

## Как это легло в v3
| Урок | Решение в v3 |
|---|---|
| сплошная форма > тонкая линия | все пять знаков — сплошные жёлтые формы; тонкого обода нет |
| жёлтый круг = монета Zcash | ни один аватар не жёлтый круг; у Visor тёмный фон, хотя жёлтый фон был сильнее |
| кольцо-затмение занято Penumbra | затмение осталось только как «укус» диска в C · Bite |
| призрак = Phantom, пилюля = pump.fun | маскот Visor — бесформенный «бугор» с цензурной полосой, без глаз и волнистого низа |
| научная схема нравится владельцу (ZecHub, zk) | A · Proof и B · Root: тёмная «бумага» с сеткой, моно-нотация, Fig. 1, без синего и без Z |
| типографика + один мотив | баннер D («Bought by» + плашка), A (statement / witness) |
| продукт как картинка | баннер C: лента «unzeen bought …» |
