# Tape peel / stick: спека микро-взаимодействия для frontend

Владелец утвердил 13.10.2026 как «вау-деталь». Прототип: `docs/brand/final/for-web/tape-peel.html` (открыть в браузере), стоп-кадр: `docs/brand/final/peel-still.png`. Ассеты: `docs/brand/final/for-web/tape-strip-simple.svg` (≤ 48 px высоты), `tape-strip-full.svg` (крупно).

## Что происходит
Лента держится за рваный (правый) конец как за петлю: `transform-origin: 92% 50%`. Свободный конец с загнутым уголком поднимается вверх, лента укорачивается в перспективе (`scaleX(.86)`), под ней появляется тень. Под лентой видно то, что она закрывала. Потом лента садится обратно.

| Фаза | Свойства | Длительность | Easing |
|---|---|---|---|
| peel (снять) | `rotate(rest + 26deg) translate(6%, -48%) scaleX(.86)`, `drop-shadow(0 14px 10px rgb(0 0 0 / .6))` | 420 ms | `cubic-bezier(.2,.8,.2,1)` |
| hold | без изменений | пока hover / hold; авто-режим — 900 ms | — |
| stick (наклеить) | обратно к `rotate(rest)`, тень → 0 | 300 ms | `cubic-bezier(.5,0,.9,.3)` (ускорение «шлёп») |

Анимируем только `transform`, `opacity`, `filter`. Никакого layout. В Motion то же самое: `animate={{ rotate, x, y, scaleX }}` с `transition={{ duration: .42, ease: [.2,.8,.2,1] }}`. Пружину не используем: отскок читается как игрушка.

## Где применяем (три места, больше не надо)
1. **Лого в шапке** (`un▬een`): hover и focus-visible снимают ленту с «z», уход курсора возвращает. При первой загрузке — один раз через ~600 ms (флаг в `sessionStorage`), без повторов и циклов.
2. **Peek** (портфель, баланс по anon-ключу): вместо blur значение закрыто лентой `tape-strip-full`. Удержание кнопки Peek снимает ленту, отпускание возвращает. С клавиатуры Space/Enter работают как переключатель, `aria-pressed`. **Значение рендерим в DOM только пока лента снята** (в прототипе оно просто прозрачное — так делать нельзя).
3. **Загрузка страницы** — только лого (п. 1). Ленту ленты сделок не трогаем: там уже есть reveal из blur, двойной эффект будет шумом.

## Доступность и fallback
- `prefers-reduced-motion: reduce`: без поворота и тени, лента исчезает и появляется за 150 ms (`opacity`).
- Лого: `aria-label="unzeen"` на ссылке. Лента — `alt=""`, скрытая «z» — `aria-hidden`.
- Фокус-кольцо 2 px `--zec`, появляется мгновенно, без анимации.
- Не запускать снятие по скроллу и таймеру повторно: максимум один авто-показ за сессию.
