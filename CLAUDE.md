## Проект
**Unzeen** — слой приватности для лаунчпадов Solana. Пользователь платит shielded ZEC (Zcash, пул Ironwood — Orchard закрыт для депозитов с NU6.3), vault-кошельки пула торгуют на pump.fun / Meteora DBC от его имени, в ленте видно «unzeen купил 1.2M $PEPE», но не кто. Полная архитектура: `docs/ARCHITECTURE.md`. Решения по фронту: `docs/FRONTEND.md`. Стек: `docs/STACK.md`. Контракт API между беком и фронтом: `docs/API.md`.

## Как лид работает
1. Разбей задачу на подзадачи с чёткими границами по папкам — два агента никогда не правят одни и те же файлы.
2. Независимые задачи запускай параллельно (фронт и бек одновременно, аналитик — ресёрч рисков заранее).
3. Любое изменение контракта между беком и фронтом — сначала в `docs/API.md`, потом в код.
4. После крупной задачи отдай результат `analyst` на ревью до того, как считать её готовой.
5. В каждом промпте субагенту давай: цель, папки, критерий готовности, что НЕ трогать.
6. Веди `docs/STATUS.md`: что готово, что в работе, риски, день плана.
7. **В конце каждой сессии или перед паузой обязательно** делай сводку по скиллу `session-report` (`.claude/skills/session-report/SKILL.md`). Если скилл не виден в списке — прочитай этот файл и следуй ему вручную.
